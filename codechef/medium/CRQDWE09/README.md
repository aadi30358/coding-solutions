## Problem

### Subtraction Operator in Java

What will be the output of the following Java program?

```
class Codechef {
    public static void main(String[] args) {
        int number = 50;
        number = number - 20 - 10;
        System.out.println("Result: " + number);
    }
}

```

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A

    public static void main(String[] args) {

}
}
