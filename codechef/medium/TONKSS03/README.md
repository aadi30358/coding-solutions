## Problem

### Worked Example - Storing and Displaying Exam Score

In this example, we will declare multiple variables of the same type in a  **single statement**, assign values, and print them in Java. This approach makes the code more concise and improves readability.

 **When executed, the code will show:** 

```
Math Score: 85
Science Score: 90
English Score: 78

```

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-16T13:40:27.431Z  

```java
class Codechef {
    public static void main(String[] args) {
        // Declaring multiple int variables in one statement
        int mathScore = 85, scienceScore = 90, englishScore = 78;

        // Printing the values of all variables
        System.out.println("Math Score: " + mathScore);
        System.out.println("Science Score: " + scienceScore);
        System.out.println("English Score: " + englishScore);
    }
}
```
